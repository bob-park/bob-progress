# 데스크톱 패널 수정과 에이전트 꼬마 Clawd: 설계 (small change)

## 의도

1.1.0 패널은 터미널에서는 정상이다. 데스크톱 앱에서는 세 군데가 깨진다.
- 캐릭터가 움직이지 않는다.
- 섹션 카드 사이에 여백이 없어서 위아래 카드가 붙어 있다.
- execute 단계의 plan 막대가 한 줄을 넘쳐 다음 줄로 내려간다.

이 셋을 고친다. 함께 데스크톱의 에이전트 줄 아이콘(지금의 로봇 비트)을 **꼬마 Clawd**로 바꾼다. 이 아이콘은 터미널에서 `[^_^]✓` 같은 글자로 나오는 부분에 해당한다.

승인된 목업은 `docs/superpowers/specs/2026-11-02-desktop-pane-mockup.html`의 **A. 꼬마 Clawd**이다.

## 목표

- **움직임**: 데스크톱에서 단계 캐릭터는 busy일 때, 꼬마 Clawd는 running일 때 움직인다.
- **여백**: 데스크톱에서 섹션 카드 사이에 여백이 생긴다.
- **막대**: 데스크톱의 execute 막대가 어떤 패널 폭에서도 한 줄 안에 들어간다.
  - 카드 안에 있을 때(`card`)와 일반 줄일 때(`plainRow`) 모두 해당한다.
  - 막대 바로 뒤의 `3/7`과 시간은 지금처럼 같은 줄에 남는다.
- **꼬마 Clawd**: 목업의 A를 그대로 그린다. 크기는 18×10 격자를 2배로 그린다.
  - 모자 색은 역할을 따른다. impl `#378ADD`, review `#E0A030`, fix `#E5534B`, 일반 `#1D9E75`.
  - 몸 오른쪽에 역할 도구가 붙는다. 렌치, 돋보기, +, 없음.
  - 표정은 상태를 따른다. 눈은 3×2 픽셀이다.
    - running: 눈을 뜬다(•).
    - waiting: 눈을 감는다(-).
    - done: 웃는다(^). 도구 자리에 초록 ✓가 그려진다.
    - failed: x 눈이다. 도구 자리에 빨간 X가 그려진다.
    - issues: o 눈이다. 도구 자리에 노란 !가 그려진다.
  - running일 때만 깡충거리고 도구가 까딱인다. 그 밖의 상태에서는 멈춰 있다.
  - SUPERPOWERS 아래 에이전트 줄과 AGENTS 섹션 모두에 쓴다.

## 비목표

- 터미널 화면의 변경. 글자 비트, 글자 막대, 레이아웃을 모두 그대로 둔다.
- 단계 캐릭터의 모양 변경. 움직이게만 만든다.
- state와 reducer 변경.

## 안티골

- 터미널 출력이 하나라도 달라지는 것. 기존 테스트로 지킨다.
- 데스크톱 애니메이션이 100ms redraw마다 처음부터 다시 시작해서 멈춘 것처럼 보이는 것.
- `prefers-reduced-motion`을 무시하는 것.

## 제약

- `Svg`는 desktop, vscode, mobile에만 있다. 분기는 지금처럼 `v.px`와 `svgOf`로 한다.
- SVG `source`는 프레임 번호(`v.f`)와 무관해야 한다. 경과 시간처럼 바뀌는 값은 SVG 밖의 `Text`에 둔다.
  - 막대 SVG는 done, active, total이 바뀔 때만 문자열이 바뀐다.
- 새 의존성은 들이지 않는다.

## Approaches

- **A. 움직이는 SVG를 `isInteractive: true`로 그린다 (선택).**
  - 렌더 API 문서에 따르면 샌드박스 frame에서는 CSS 애니메이션이 확실히 돈다. 이미지 모드는 그렇다고 보장하지 않는다.
  - 대가는 캐릭터마다 frame이 하나씩 생긴다는 점이다.
- B. 프레임마다 SVG를 새로 만든다. 초당 10번 이미지를 새로 만들어서 깜빡일 위험이 있다.
- C. 원인을 먼저 실험으로 확인한 뒤 고른다.

사용자가 A를 골랐다.

## 정해진 것

- 작업 브랜치는 `fix/desktop-pane`이다.
- 에이전트 아이콘은 목업 A(꼬마 Clawd)로 한다.
- 데스크톱 애니메이션은 `isInteractive: true`로 돌린다.

## 내 판단 (확인해 주세요)

- **여백.** `hooks/register.tsx`의 바깥 `Box`에 `gap="sm"`을 준다.
  - 터미널에서는 `sm`의 세로 간격이 0줄이라 터미널 화면이 그대로 유지된다.
- **데스크톱 막대.** 데스크톱에서만 글자 막대 대신 SVG 막대를 그린다.
  - 구성은 `[SVG 막대(남은 폭을 채움)] 3/7 시간`이다.
  - 초록(done), 노랑(active), 회색(todo) 비율로 칸을 나눈다.
  - busy일 때 active 칸 위에 밝은 띠가 CSS로 지나간다. 지금 터미널에서 지나가는 bright cell에 해당한다.
- **움직이지 않는 SVG.** 끝난 단계의 1배 캐릭터, 멈춘 꼬마 Clawd, 막대(idle일 때)는 이미지 모드로 둔다.
  - `isInteractive`는 움직일 때만 켜서 frame 수를 줄인다.
- **버전.** 1.1.0에서 1.2.0으로 올린다. 아이콘 모양이 바뀌기 때문이다.
- **README.** 에이전트 아이콘 설명을 데스크톱의 꼬마 Clawd로 고친다. GIF와 스크린샷은 다시 찍지 않는다(터미널 녹화이다).

## 빌더에게 남긴 것

- **파일.** `hooks/characters.ts`의 `botSvg`를 꼬마 Clawd로 다시 쓴다.
  - 시그니처는 그대로 둔다.
  - 격자, 눈, 도구, 표시는 목업 스크립트의 `BODY.clawd`, `EYES`, `TOOL`, `MARK`를 옮긴다.
  - `stageSvg`와 `botSvg`는 움직일 때 `isInteractive: true`를 붙인다.
  - 막대 SVG 함수(예: `barSvg(done, active, total, on)`)도 같은 파일에 둔다.
- **막대 폭.** 데스크톱에서는 막대를 `flexGrow={1}`인 Box에 넣는 방식을 먼저 시도한다.
  - SVG의 `width`는 생략하거나 `viewBox`만 준다.
  - 이 방식으로 폭이 채워지지 않으면, 셀 폭에서 대략의 픽셀 폭을 계산하는 방식으로 정한다.
- **확인 (필수).** 실제 데스크톱 앱에서 네 가지를 본다.
  - ① 단계 캐릭터와 꼬마 Clawd가 움직이는지 본다.
  - ② 100ms redraw 때 애니메이션이 처음부터 다시 시작하지 않는지 본다.
  - ③ 카드 사이에 여백이 있는지 본다.
  - ④ 좁은 패널과 넓은 패널 모두에서 막대가 한 줄에 들어가는지 본다.
  - ②가 실패하면 고치지 말고 사용자에게 가져온다. 데스크톱에서 ticker를 끄면 스피너도 멈추기 때문에, 그 결정은 사용자가 한다.
- **테스트.** export한 순수 함수만 단위 테스트한다.
  - `botSvg`가 상태 5가지마다 다른 눈과 표시를 내는지 본다.
  - running일 때만 `isInteractive`가 붙는지 본다.
  - 같은 입력이면 같은 문자열이 나오는지 본다.
  - `barSvg`의 비율 rect 폭을 본다.
  - 기존 터미널 테스트는 그대로 통과해야 한다.
