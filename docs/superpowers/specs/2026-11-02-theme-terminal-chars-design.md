# 하얀 배경, 터미널 꼬마 Clawd, 별명 위치, 데스크톱 막대: 설계 (small change)

## 의도

1.2.0을 데스크톱 앱과 터미널에서 직접 써 봤더니 다섯 가지 문제가 나왔다.

- **공통**: 하얀 배경에서 SUPERPOWERS 영역이 잘 안 보인다.
- **터미널**
  - 에이전트 줄에 작은 캐릭터가 없다.
  - 단계 사이 여백이 생기지 않았다.
  - 별명 위치가 애매하다.
  - 작업 막대가 있는 execute 카드에서는 별명이 아예 안 나온다.
- **데스크톱**: execute 단계의 막대가 보이지 않는다.

목업은 `docs/superpowers/specs/2026-11-02-theme-terminal-chars-mockup.html`이다. 사용자는 1번에서 **C**, 2번에서 **T1**을 골랐다.

## 목표

- **별명 위치 (C, 터미널·데스크톱 공통)**
  - 현재 단계 카드의 오른쪽 열 첫 줄을 별명(굵게)으로 한다.
  - 그 아래는 단계 머리(`⠹ execute  05:02`), 막대, 지금 작업 순서이다.
  - 막대가 있는 execute에서도 별명이 나온다.
  - 막대가 없는 단계는 별명과 단계 머리, 두 줄이다.
  - 터미널 캐릭터는 4줄이다. 그래서 execute 카드는 줄 4개가 캐릭터와 나란히 맞는다.
- **터미널 꼬마 Clawd (T1)**
  - 에이전트 줄 맨 앞의 글자 비트 `[•_•]⚙`를 바꾼다. 새 모양은 `▐•_•▌⚙`이다.
    - `•_•`: 배경색 점토색(`#D97757`), 글자색 짙은색(`#1F1E1D`)
    - `▐`·`▌`·도구: 역할 색
  - 표정과 도구는 지금 글자 비트와 같다.
    - running: `•_•` ⚙ / ✲ (3틱마다 번갈아)
    - waiting: `-_-` z
    - done: `^_^` ✓
    - failed: `x_x` ✗
    - issues: `o_o` ⚠
  - 폭은 지금처럼 `BOT_W` = 7칸이다. 줄 수는 그대로다.
- **터미널 단계 사이 여백**: SUPERPOWERS 단계 사이와 섹션 사이에 터미널에서도 빈 줄 1줄을 둔다. `gap`을 `'sm'`에서 `'md'`로 바꾼다. `md`는 터미널에서 세로 1줄이다.
- **데스크톱 막대 (①a)**
  - SVG 막대를 Box 세 개로 바꾼다. 각 Box의 `backgroundColor`와 `flexGrow`는 아래와 같다.
    - 완료: `success`, `flexGrow` = done
    - 진행: `warning`, `flexGrow` = active
    - 남은 것: `inactive`, `flexGrow` = todo
  - 값이 0인 칸은 그리지 않는다.
  - 높이는 1줄이다. 감싸는 Box에 `flexGrow={1}`을 줘서 남은 폭을 채운다.
  - 데스크톱 막대 위의 반짝이는 띠는 없앤다.
  - `barSvg`는 지운다.
- **하얀 배경 (②a)**
  - **글자색**: SUPERPOWERS, TASKS, AGENTS 영역에서 직접 쓴 색 이름과 hex를 테마 키로 바꾼다.
    - `'yellow'` → `warning`
    - `'green'` → `success`
    - `'blue'` → `suggestion`
    - `'red'` → `error`
    - 흐린 글씨는 지금처럼 `dimColor`로 둔다.
  - **반짝임**: 터미널의 `shimmer` 밝은 칸(`#fff3c4`, `#f0cf6e`)은 하얀 배경에서 사라진다. 그래서 색을 바꾸는 대신 `bold`와 `inverse`로 강조한다.
  - **데스크톱 SVG 캐릭터**
    - 흰 픽셀(`W`, `w`)과 연한 픽셀(`L`, `u`)은 밝은 배경에서 진한 회색 계열로 바꾼다.
    - 방법은 SVG 안의 `@media (prefers-color-scheme: light)` CSS이다. 호스트 화면의 색 구성을 따르므로 `$.config`를 읽지 않는다.
    - 그래서 `layer()`는 해당 픽셀에 class를 붙이고, 색은 CSS가 정한다.
  - **터미널 캐릭터 글자**: 소도구 색 `C.fg`(`#e8e6df`)도 하얀 배경에서 안 보인다. 테마 키 `text`로 바꾼다.

## 비목표

- main, SKILLS, ACTIVITY 섹션의 색 정리. 이번에는 사용자가 지목한 SUPERPOWERS 쪽과, 같은 막대를 쓰는 TASKS, 같은 에이전트 줄을 쓰는 AGENTS만 다룬다.
- 데스크톱 꼬마 Clawd의 모양. 1.2.0 그대로 둔다.

## 안티골

- 어두운 배경에서 지금보다 덜 보이게 되는 것.
- 터미널 줄이 패널 폭을 넘는 것. 지금 42칸 검사를 유지한다.
- 데스크톱 막대가 또 안 보이거나 넘치는 것.

## Approaches

- **① 데스크톱 막대**
  - **a. Box 배경색과 flexGrow (선택).** 레이아웃이 폭을 맞추고 색은 테마를 따른다. 데스크톱 반짝임은 사라진다.
  - b. SVG를 유지하고 픽셀 폭을 추정한다. 반짝임이 남지만 폭 추정이 틀릴 수 있다.
- **② 하얀 배경**
  - **a. 글자는 테마 키, SVG는 테마에 맞춘 색 (선택).**
  - b. 어느 배경에서도 읽히는 중간 색 하나로 고정한다. 어두운 배경에서 탁해진다.

사용자는 ①a, ②a를 골랐다.

## 정해진 것

- 브랜치는 `fix/theme-terminal-chars`이다.
- 별명 위치는 C, 터미널 에이전트 줄은 T1이다.
- 데스크톱 막대는 ①a, 하얀 배경은 ②a로 한다.

## 내 판단 (확인해 주세요)

- **SVG의 테마 판단.** ②a는 "테마를 읽는다"였다. 하지만 SVG는 `$.config`의 테마 값 대신 CSS `prefers-color-scheme`으로 판단한다.
  - 이유는 두 가지다. 데스크톱 앱 자체의 밝기 설정이 `/config` 테마와 다를 수 있다. 그리고 `auto` 테마는 값만 보고 밝은지 어두운지 알 수 없다.
  - 그래도 데스크톱에서 색이 안 바뀌면, `$.config`의 `theme` 값에 `light`가 들어 있는지로 판단하는 방법으로 바꾼다.
- **여백 값.** 데스크톱의 `md`가 너무 넓어 보이면 데스크톱만 `sm`으로 되돌린다.
- **버전.** 1.2.0에서 1.2.1로 올린다. 수정 위주의 변경이기 때문이다.
- **README.** 터미널 꼬마 Clawd(`▐•_•▌⚙`), 별명 위치, 테마 대응을 반영해 고친다.

## 빌더에게 남긴 것

- **테스트.**
  - `botFrame`이 새 모양을 내는지 본다.
    - 폭은 7칸이다.
    - 상태 5가지마다 표정이 다르다.
    - running은 프레임에 따라 바뀌고, 나머지 상태는 바뀌지 않는다.
    - 얼굴 조각에 점토색 배경이 있다.
  - execute 카드 첫 줄에 `망치 대장장이`가 있는지 본다.
  - 데스크톱 막대에 Svg가 없고, `backgroundColor`가 있는 Box가 있는지 본다.
  - SUPERPOWERS와 TASKS 트리에 `'yellow'`, `'green'`, `'blue'`, `'red'` 색 문자열이 없는지 본다.
  - 바깥 Box의 `gap`이 `'md'`인지 본다.
  - SVG 소스에 `prefers-color-scheme: light`가 들어 있는지 본다.
- **확인 (필수).** 머지 전에 확인한다. 하얀 배경과 어두운 배경의 터미널, 그리고 데스크톱 앱(가능하면 밝은 모드)에서 아래를 본다.
  - 별명이 C 위치에 나오는지
  - T1 캐릭터가 보이는지
  - 단계 사이에 여백이 있는지
  - 데스크톱 막대가 보이는지
